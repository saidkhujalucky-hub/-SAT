# Файлы для GitHub Pages

1. Распакуй архив и открой папку SAT_GitHub_Pages.
2. Загрузи содержимое этой папки в корень репозитория своего сайта. index.html должен лежать в корне, рядом с app.js и style.css. Сам ZIP загружать вместо файлов не нужно.
3. Если в репозитории уже есть прежние версии этих файлов, замени их. Настройки действующего GitHub Pages можно оставить прежними.

## Что заработает после загрузки

Прежний тренажёр с внешними вопросами College Board открывается через index.html. Он сохраняет попытки локально и зависит от доступности внешнего сервиса вопросов.

## Подключение новых функций

Регистрация, кабинет, обучение, серверные авторские тесты и сохранение прогресса требуют отдельного Node.js API. GitHub Pages не запускает этот сервер.

1. Разверни сервер из полного проекта SAT_Preparation_Platform.zip согласно его README.md.
2. В этом наборе открой config.js и впиши реальный HTTPS-адрес API с окончанием /api.
3. На сервере укажи ALLOWED_ORIGINS=https://saidkhujalucky-hub.github.io (без /SAT.4/).
4. Загрузи обновлённый config.js в репозиторий.

Адрес API пока не указан. Без него кабинет покажет сообщение о недоступности сервера; новые серверные функции не будут работать. Здесь нет поддельной регистрации или имитации сохранения.

В архив входят только публичные файлы. База данных, .env, сервер и закрытый исходный банк заданий сюда не включены. Оплаты нет.
